# MarketFixer frontend

Landing page-ul folosește React, Vite și SCSS.

```sh
cd frontend
npm install
npm run dev
```

Serverul de dezvoltare trimite cererile API către backend-ul de pe portul 3000. Pentru a actualiza fișierele servite de backend, rulează `npm run build`. Pagina existentă de scanare și raport este păstrată în `backend/public/audit.html`.
